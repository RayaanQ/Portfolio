01 / 052026 · ML Forecasting

            
Community Crisis Predictor

            
Forecasts community-wide mental-health crises from Reddit up to a week before they happen. It treats subreddits like weather systems: an LSTM reads 8 weeks of language, sentiment and topic drift and predicts next week's distress state.

            
  • PyTorch LSTM
  • XGBoost
  • BERTopic
  • SHAP
  • Streamlit
  • LLM briefs

02 / 05Jul 2025 · GenAI · Chrome Extension

            
Multi-Modal AI Web Page Summarizer

            
A Chrome extension that reads the page you're on, including embedded PDFs, text inside images and YouTube transcripts, then summarizes it and lets you chat with it. RAG pulls in live web search for context the page doesn't have.

            
  • LangChain Agents
  • RAG

  • FastAPI
  • Tesseract OCR
  • Docker

03 / 05Aug 2025 · Hackathon · RegTech

            
JurisTrack — Geo-Compliance Radar

            
Scans social-platform feature specs for region-specific legal risk (EU DSA, CCPA, Utah, Florida, NCMEC). It decodes internal jargon, scores risk and links every flag to the clause that triggered it.

            
  • FastAPI
  • Gemini
  • TF-IDF retrieval
  • Explainable AI
  • React
  • Recharts

04 / 05Dec 2024 · Sustainable Software

            
Greenory — Intelligent Carbon Tracker

            
Estimates the carbon footprint of your code and suggests lower-carbon rewrites. It parses Abstract Syntax Trees first so the LLM only sees the hotspots. Fewer queries means lower cost and less energy, which is the whole point.

            
  • AST analysis
  • LLM suggestions
  • GitHub integration
  • Energy modelling

            

              
            

          

          
        


        
        

          

          

            
05 / 05Jan 2024 · EdTech · Accessibility

            
LingoLeap — Speech Therapy, Gamified

            
A web app for children in Hindi-speaking communities with misarticulation. Speech recognition checks pronunciation, and game mechanics keep kids coming back to practise between therapy sessions.

            
  • Next.js
  • TypeScript
  • Node.js
  • MongoDB
  • Speech recognition
  • JWT
